# 🤖 n8n ChatGPT – Chatbot com integração n8n

**n8n ChatGPT** é um chatbot desenvolvido em Flutter que conecta usuários a agentes de Inteligência Artificial criados com fluxos automatizados na plataforma n8n.

<img alt="n8n ChatGPT" src="https://i.imgur.com/q5vXV9e.png" />

---

## ✨ Recursos

- 🤖 Integração com agentes de IA via **n8n**
- 🎙️ Reconhecimento de fala (**Speech-to-Text**)
- 🔊 Sintetização de voz (**Text-to-Speech**)
- 📱 Interface intuitiva e responsiva em Flutter
- 🧠 Conversas fluídas e interativas em tempo real

---

## 🚀 Primeiros Passos

### Pré-requisitos

- Flutter 3.x
- Credenciais configuradas no seu servidor n8n
- Xcode (para iOS) ou Android Studio (para Android)

### Clonar e Executar

```bash
git clone https://github.com/mosqueiro/n8n-chatgpt
cd n8n-chatgpt
flutter pub get
flutter run
```
